# 豊無線株式会社 ホームページ（リデザイン版）

静的HTML/CSS/JSのみで作成した、ビルド不要・維持費ほぼ0円のサイトです。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | 豊無線株式会社のコーポレートサイト（1ページ完結） |
| `kscovo.html` | 新事業「kscovo」のブランドページ（別ブランド風デザイン） |
| `style.css` | 共通スタイル（`theme-corp` / `theme-kscovo` でテーマ切替） |
| `script.js` | ナビ開閉・スクロール演出などの共通スクリプト |

外部依存はGoogle Fonts（無料）とGoogleマップの埋め込み（無料・APIキー不要）のみで、
サーバーサイドやデータベースは使用していません。

## 公開方法（維持費0円の候補）

1. **GitHub Pages**：GitHubリポジトリにこの4ファイルを置き、Settings → Pages で公開するだけ。無料。
2. **Netlify Drop**：https://app.netlify.com/drop にこのフォルダをドラッグ&ドロップするだけで公開URLが発行されます。無料。
3. **Cloudflare Pages**：同様に無料で高速なCDN配信が可能です。

どれもサーバー管理やアップデート作業が不要なため、運用の手間・費用を最小限に抑えられます。
独自ドメインを使う場合は、各サービスの案内に沿ってDNS設定を追加してください。

## 公開前に確認してほしい項目

- `kscovo.html` のオンラインストアへのリンクは、実際のストア（https://kscovo.stores.jp/）に設定済みです。
- 会社情報（商号・代表者・所在地・資本金・古物商許可番号など）はご依頼内容に沿って反映済みです。
  電話番号・FAXなど変更していない項目は既存のまま残しているため、最新の情報と相違がないか一度ご確認ください。
- ロゴは現在テキストベースの仮デザインです。正式なロゴ画像があれば
  `.brand-mark` 部分を `<img>` に差し替えると、より本格的な見た目になります。

## デザインの考え方

- **豊無線本体**：紺×アクア系のモダンな配色で「ものづくり×IT」らしい信頼感を表現。
- **kscovo**：実店舗（kscovo.stores.jp）が扱う1950〜80年代の英国ヴィンテージ食器のトーンに合わせ、
  マスタード×テラコッタ×オリーブの温かみあるレトロカラーと明朝体で、別ブランドらしい上質感を表現。
- 両者は同じCSSファイル内のテーマ変数で管理しているため、色や余白の微調整は
  `style.css` の `:root` / `.theme-corp` / `.theme-kscovo` の数値を変えるだけで反映されます。
